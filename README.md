# Kalshi Control — phone-first paper-trading dashboard

## Safety and scope
- Paper-trading only. No live order endpoint, account connection, or code path that places real Kalshi orders.
- Public market data only.
- HTTP Basic login is required for all dashboard/API routes except `/api/health`.
- Configure `APP_PASSWORD` as a secret environment variable in your host. Username is `kalshi`.
- Do not commit passwords, API private keys, or account secrets.
- Paper settings and positions are stored in the browser's local storage. They are not synced between devices and may be lost if browser storage is cleared.
- The daily loss stop blocks new simulated entries based on realized daily paper losses. It does not liquidate positions.
- Current quotes are not guaranteed execution prices. The simulator omits fees, queue position, partial fills, latency, and settlement edge cases.

## Deploy on Render
1. Upload this repository to a **private** GitHub repository.
2. In Render, choose New > Web Service and connect the repository.
3. Choose Docker as the runtime.
4. Set Dockerfile Path to `Dockerfile` (repository root).
5. Add environment variable `APP_PASSWORD` with a long, unique password generated by a password manager. Do not put it in GitHub or ChatGPT.
6. Deploy. Render supplies `PORT`; the Docker command listens on it.
7. Open the service URL. Safari will prompt for HTTP Basic authentication. Username: `kalshi`; password: the value you set for `APP_PASSWORD`.
8. Verify `/api/health` returns `{"ok":true,...}`. Then open the dashboard root URL.

## Important hosting limitation
Render's free web services may sleep when idle. They are suitable for initial dashboard testing, not guaranteed always-on market monitoring. Choose an always-on paid plan only after evaluating costs and reliability.

## Run locally
Requires Python 3.11+:
```bash
pip install -r requirements.txt
APP_PASSWORD='choose-a-long-password' uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Data source
Read-only market data is requested server-side from Kalshi's public market-data API. No authenticated Kalshi API key is needed for these public endpoints.
